Your design

Drop your tokens. The canvas wears them.

Whatever your design tool already exports will do: a DTCG or Tokens Studio export, a Figma variables dump, or any nested JSON of names and values. Colour, spacing, radius, the type ramp and shadows come across. Components and fonts never do. The file is read in your browser and never uploaded, because this site is static and has nowhere to upload it to.

or

No export to hand? Give the canvas one brand colour and the contrast engine derives the rest of the palette from it.

The mapping is by role, never by name: your export's ramps are read for what each one does, then negotiated against the same WCAG pairs the derive engine is held to. The report says which ramps were used, what was changed to pass, and what still fails.

The same engine produced the packs committed in this repo, and the same one runs behind the Figma import command. One mapping engine, three front doors.

The studio

A product's shape, on a canvas you can move.

This canvas starts empty. What fills it is a real recorded agent run — one brief about a field-service dispatch tool, read once, and eighteen build ops played back in the order and at the pacing shape the run itself had, narration and refused calls included. There is an industry name for that: a management flight simulator, illustrative rather than predictive — you watch decisions run and consequences land, then take the controls yourself.

Each block the run leaves behind is one place a person can be, with what they can do from there listed inside it. The moment you touch the canvas it is yours: the run pauses, and you drag a block by its handle or press Enter on it and use the arrow keys. Every move is announced and every move undoes. The blocks are sketches until you compile them: press Compile the board and the same rules that name a pattern on the builder run here, one step at a time, until each block is the real component its slot calls for, in the slot you left it in. Back to blocks plays it again. What compiles is a connected flow: each place becomes a screen, and every connection the run drew becomes a working navigation between them. The compile runs declarative generative UI: each screen is proposed as data, then validated against the generated component vocabulary before any of it renders.

Below the run's blocks sit the two prototypes this platform actually shipped — Verdant's phone screen and Fieldwork's dispatch board — running for real inside device frames on the same canvas, each openable on its own page. Move them by the same handle, and drag the corner (or press Enter on it and use the arrow keys) to resize them. They wear this site's design tokens like everything else here; a token export you drop above re-skins the canvas around them, not the pages inside them.
