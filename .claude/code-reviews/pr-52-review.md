## What's good

- **The PR's own flagged risk — `translate` vs `transform` — is spec-correctly handled, not lucky.** `card-rise` animates the standalone `translate` property; `.card-link:hover` transitions `transform`. Per CSS Transforms L2 these are independent, composed properties, so a revealed card's frozen `translate:0 0` (`fill:both`) and the hover `translateY(-2px)` stack. Empirically confirmed in the report (reveal-then-hover lift = 2.00px).
- **No hidden start-state leaks anywhere.** Every `opacity:0`/`translateY`/`scaleX(0)`/`background-size:0%` "from" state lives strictly inside `@media (prefers-reduced-motion: no-preference)` and/or `@supports (animation-timeline: view())`; every base rule renders at-rest/visible. This is the #1 baseline-safety gotcha and it holds — the 16/16 stage-1 green is earned.
- **Clean accessibility on the card conversion:** whole-card links, zero nested anchors, decorative glyphs `aria-hidden`. The collapsed `.verify-proof` uses `grid-template-rows:0fr` + `overflow:hidden`/`min-height:0` on the inner span (not `display:none`/`visibility:hidden`), so it stays in the a11y tree — the detail most "grid-rows reveal" implementations get wrong.
- **`build-tokens.mjs` correctly extended** to strip `duration`/`easing` from iOS/Android targets (prevents a Swift/Kotlin constant literally holding a `linear(…)` string) while keeping them on the web target.
- **`portfolio.js` correct:** speculation-rules feature-detect via `HTMLScriptElement.supports("speculationrules")`, `href_matches:"/*"` scopes to same-origin docs, prefetch (not prerender) keeps analytics clean; header scroll listener is rAF-throttled.
- **Honesty fix verified true against source, not merely asserted.**
