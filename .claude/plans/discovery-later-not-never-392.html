Later, not never

Build brief for ticket #392 · the full plan, with every trap and line number, is discovery-later-not-never-392.md.

What we're building and why

Today a discovery session can only record "we are not doing X", and the generated PRD files it as a refusal. After this ticket it can also record "not yet", under its own heading, Later, not never, beside Non-goals.

The concepts this rests on

1. A projected document

The PRD is never written. It is computed from a log of recorded decisions (the projection), so every line on the page traces back to one recorded entry.

Why here: a parked item cannot appear until something records it. So we add a question that produces a record, not a paragraph.

till receipt
  every line came from a scanned item
  nobody types onto the receipt
  no scan, no line

2. A refusal is not a deferral

A non-goal is "no, and here is why". A parked item is "not yet, and keeping it possible changes how we build now". Filing the second under the first loses the difference.

Why here: one new question asks for the deferral in the person's own words, and one new section keeps it apart from the refusals.

Non-goals          no messaging between holders (why: appetite)
Later, not never   a waiting list for plots (later: rota trusted first)

3. Pinned numbers

A pin is a value copied by hand into the test that guards it. Change the real thing without changing the copy and the test fails, naming both.

Why here: the question list, its length and the number of PRD sections are all pinned, so this plan names every copy that must move with them.

bank.mjs        list = 31 questions
build-checks    expects 31          ← must move in the same change
mismatch        red, by name

4. A real run as evidence

The session's files are written only by the server while a person answers in the browser (append-only: lines are added, never edited). Nobody may type or fix them by hand.

Why here: the last step is one real, paid session that asks the new question, so the feature is shown working rather than claimed.
