The as-is record

Brief for ticket #486. The full plan: as-is-ground-truth-486.md

What we're building and why

Today a discovery run ends with a PRD: the product someone wants to build. After this ticket, it also ends with a short record of how the work really went the last time it happened, with every wish marked.

The concepts this plan rests on

1. As-is versus to-be

"As-is" is how things work today. "To-be" is the planned product. Builders need both kept apart, because a plan can look like the truth when it is only a guess.

as-is.md  → what happened (facts)
prd.md    → what we want (concept)

2. One named past case

"Tell me about last Tuesday" gets facts. "How do you usually do it?" gets a tidy story. The record uses the answer to the question that already asks for one real, recent instance.

3. A projection (a fold)

A projection is a page computed from saved data by fixed rules, with no judgement. The same input always gives the same page, so a check can compare it byte for byte. It is like a spreadsheet formula: it reads cells and never edits them.

4. Flag, don't delete

A sentence that sounds like a wish or a guess ("we'd like…", "it will…") gets a visible mark and stays on the page. Deleting it would hide what the person said.

> The sous chef posted a photo at 7.40.
8 · flagged: conditional
> …which will scroll off the group in a fortnight.
