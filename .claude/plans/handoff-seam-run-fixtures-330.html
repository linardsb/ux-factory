Committing the two test runs as evidence

Full plan: handoff-seam-run-fixtures-330.md

What we're building and why

Two AI agents were given only the design handoff pack and asked to build against it; their work sits on a Desktop. After this ticket it lives in the repo, byte for byte, with a label saying exactly what each agent saw and was told.

The concepts this plan rests on

A fenced run

An agent started in an empty folder holding only the pack, told not to look elsewhere. It shows what a stranger would have to ask. Like giving a new hire only the manual and noting every question.

Evidence stays unedited

The copied files must match the originals exactly, checked by a byte-for-byte comparison. Fixing even a typo would turn a real record into a written one.

diff -r  Desktop/seam-run   repo copy
  → no output = identical

Provenance

Provenance (where something came from) is stated beside the files: the pack's exact git commit, the launch command, the prompt. Where a fact was not kept, the label says so rather than guessing.

A check that can fail

CI already syntax-checks every tracked script. We prove it reaches the new server file by breaking it on purpose and watching CI go red.

How the pieces fit

Desktop runs→ copy, minus pack repo fixtures→ compare identical bytes+ README label→ CI syntax check

The plan at a glance

  • Phase 0: owner supplies the two original prompts (they were not saved on disk).
  • Phase 1: copy both runs into a fresh branch; independent of Phase 0.
  • Phase 2: write one README per run; needs Phases 0 and 1.
  • Phase 3: run the gates, commit, open the PR.
