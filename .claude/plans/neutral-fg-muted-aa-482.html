Muted grey fix

Full plan: neutral-fg-muted-aa-482.md

What we're building and why

Today the site's grey caption text is slightly too faint on light-grey cards, so every design import is marked as failing. After this change the grey is a touch darker, passes the readability rule, and a faithful import can finally show green.

The concepts this plan rests on

Contrast ratio

A number for how much text stands out from its background. The accessibility standard (WCAG) asks for at least 4.5 for normal text. Our grey scores 4.40 on cards; the new one scores 4.53.

Design tokens

Named colours the whole site uses instead of raw values, like a paint catalogue. Change one entry and every page, export and download that reads it follows. This plan edits one entry, then regenerates the files built from it.

A verdict built from two measurements

An import reads green only if its colours match the drawing (a ΔE colour-difference score under 5) and every contrast pair passes. One failing pair makes everything red, however good the match.

green = colours match AND all 12 pairs pass

A check that can fail

A test that recomputes the answer it is checking can never go red. The new check compares against the expected word, green or red, and was shown to fail on the old grey.
