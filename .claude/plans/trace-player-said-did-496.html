Said or Did

Brief for .claude/plans/trace-player-said-did-496.md, which is the source of truth.

What we're building and why

Today the trace player shows an agent's words and its actions as identical cards. After this change, every card says whether the agent said it or did it, and the page explains why that difference matters.

The concepts this plan rests on

1. A claim versus a record

When an agent explains itself, that explanation is a claim. A tool call is a record of what actually ran. Research found that reasoning models mentioned the hint that changed their answer only 25–39% of the time. Readers should weigh the two kinds of card differently.

2. One decision, used everywhere

The card's shape, its label and the act's count all come from the same field on the step: kind. They can't contradict each other because they all read from that one place.

kind "text" → Said
kind "tool" → Did
anything else → shown as-is, never guessed

3. An accessible name

Screen readers announce an element by its accessible name, which is the short label assistive technology reads out. Each card points its name at its visible label (aria-labelledby), so the card is announced as "Said" or "Did" when you reach it.

4. A check that runs the real page

A journey driver is a script that opens the real page in three browsers and checks what appears. It takes the expected numbers from the trace file itself rather than hard-coding them. Each check is also tested by breaking the code on purpose and confirming the check fails.
