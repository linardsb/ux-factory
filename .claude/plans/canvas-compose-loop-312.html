The compose loop

Build brief for canvas-compose-loop-312.md.

What we're building and why

Today, the owner arranges every screen on the build canvas by hand. After this change, an AI agent proposes one screen at a time, with its reason. The owner accepts or refuses each one, and every step is written down.

The concepts this rests on

Propose, then decide

The agent can only suggest. A suggestion becomes part of the design only when the owner says yes.

That keeps the design the owner's own. Nothing the agent drafts slips in unseen.

agent:  proposed  (seq 7)
owner:  accepted  answers seq 7

An append-only ledger

The ledger is a file where lines can be added, never changed or removed. Undo adds an "undone" line rather than deleting one.

So "proposed, accepted, then undone" stays readable forever.

A fence

A fence is a rule that checks every tool the agent tries to use. Anything but the one proposal tool is refused, and each refusal is written down.

Like a guard with one name on the list, who logs everyone turned away.

A fake agent for testing

A fake agent is a script that plays the model's part for free. The real parts run around it.

It proves the wiring works. Only one short paid run shows how the real model behaves.
