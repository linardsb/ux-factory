The prototype studio's substrate, raw. The stage below is ordinary DOM holding real components from the system's own vocabulary — so the token contract, focus order and the inspect bubbles keep working by construction rather than by re-implementation. Pan is native scrolling; zoom is a data-zoom attribute against a scale table declared in CSS; arrangement is data-col / data-row, and moving something rewrites exactly those two attributes. Nothing here writes an inline style.

The stage

What is live: drag the background to pan, or scroll it. ⌘/Ctrl with the wheel — and a trackpad pinch, which arrives the same way — zooms about the cursor. The four buttons are the keyboard path, and the readout announces. A bare wheel is never intercepted: it scrolls the stage and then chains to the page.

Moving things: drag a component by its grab handle or by its body. Or click the handle once to pick the component up without dragging at all, move the pointer, and click again to drop it. Or do the whole thing from the keyboard: Tab to a handle, Enter to pick up, arrow keys to move, Enter to drop. Escape cancels either way and puts the component back where it started. An occupied cell is skipped rather than landed on.

Every move is announced by the slot it landed in, and every move is undoable — the Undo and Redo buttons, or ⌘/Ctrl + Z. Both input paths do the same thing: they emit one action on the site's action bus, and a single consumer applies it. That is why the keyboard path produces the identical result rather than a second implementation that agrees today.

Tab reaches every component on the stage and the browser scrolls each one into view, because this is a real scroll container and not a translated element. That property is the whole reason pan is scroll.

Placement is still programmatic — place(node, {col, row}) — but arrangement is now the reader's. Marquee select, alignment guides and multi-move are ticket #217; a layers list is #221. This page exists so the substrate can be driven and gated before anything designed depends on it.
